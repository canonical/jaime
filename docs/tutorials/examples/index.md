# Examples

Real incidents handled end to end with Jaime, one per page. Each example walks
the same arc: a workload becomes unhealthy, an incident opens, a diagnosis is
asked for, and the fix is applied and verified. Examples cover both the machine
subordinate charm (`jaime`) and the Kubernetes standalone charm (`jaime-k8s`).
